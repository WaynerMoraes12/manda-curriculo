# Segurança

Achou uma falha de segurança no Manda Currículo ou neste site, como algo que deixa outra pessoa ver ou
mudar os dados de alguém? Por favor, **não abra uma Issue**: as Issues são públicas.

Avise em particular pela aba **Security** deste repositório, no botão **Report a vulnerability**. Só quem
mantém o projeto vê o que você escrever ali.

Conte o que encontrou, como reproduzir e a versão do programa (ela aparece em "Configurações"). Não mande
dados pessoais seus ou de outras pessoas, senhas, chaves de IA nem currículos.
